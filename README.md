# Voltopia hub

Public dev hub and browser prototype for Voltopia, a storybook adventure set in the real Volturara Irpina.
Hosted free on GitHub Pages: every push to main updates the site.

- Site: https://m1k3yf.github.io/voltopia-hub/
- Play: https://m1k3yf.github.io/voltopia-hub/play/
